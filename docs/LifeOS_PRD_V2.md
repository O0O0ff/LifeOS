# LifeOS V2 — 产品需求文档 (PRD)

## 1. 产品定位与愿景

**定位**: “知识工作者与自律达人的 Strava” —— 专注时间规划、追踪与成就可视化的社交型效率工具。
**愿景**: 填补“计划 (Intent)”与“现实 (Reality)”之间的断层。通过极低摩擦的多端时间追踪，结合绝美的“成就卡片”分享，用“社交货币”驱动产品自增长 (PLG)。

## 2. 核心模块 (P0 - MVP)

### 2.1 日历与时间规划 (Intent)

- **时间块管理**：支持将待办任务拖拽至日历，生成“计划时间块”（半透明/虚线框）。
- **外部日历集成**：与 Google Calendar / Apple Calendar 同步，统一规划视图。

### 2.2 时钟与追踪引擎 (Reality)

- **跨端毫秒级同步**：无论在手机还是电脑端，点击“Start”，所有设备的状态与倒计时必须瞬间同步。
- **计划 vs 实际偏差视图**：停止计时后，日历生成“实际时间块”（实心色）。视觉上直观呈现计划时间与实际耗时的重叠、延误或超前。
- **极低摩擦的追踪入口**：
  - **PC端 (Tauri)**：全局快捷键唤起系统托盘/桌面悬浮窗，一键启停。
  - **移动端 (Expo)**：支持 iOS 灵动岛 (Live Activities) 及桌面小组件。

### 2.3 个人记录与可视化分享 (Viral Loop)

- **成就卡片生成器**：一键将数据（如“今日专注热力图”、“本周深度工作 40 小时”）生成设计感极强的图片/海报。
- **数据脱敏与隐私边界**：分享前提供“隐私遮罩”功能，保护用户具体项目隐私。
- **公共主页 (Public Profile)**：用户专属分享链接，展示连续打卡与时间分配图表，作为“自律数字名片”。

## 3. 核心非功能需求 (NFRs)

- **NFR-1 离线可用**：核心记录必须能在弱网环境进行，恢复网络后自动解决冲突并同步。
- **NFR-2 极致弹性与冷启动**：系统需适应裂变带来的突发流量（Serverless 架构），分享页面的数据库查询冷启动必须在 300ms 以内。
- **NFR-3 社交抓取完美**：公开分享链接必须能被 Twitter/微信 抓取到完美的 `og:image` 预览图。
